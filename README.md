# Personal Bio Links Profile

A personalized, highly responsive bio link and profile website designed to showcase my identity, interests, and social media presence in one clean, interactive space. 

**Live Link:** [profile-mu-woad.vercel.app](https://profile-mu-woad.vercel.app)

---

## 📑 Project Overview

This project serves as a dynamic digital business card and personal hub. Built with a focus on smooth user experience and sleek aesthetics, it brings together social profiles, musical tastes, and personal milestones into a single cohesive layout. 

The application features a beautifully integrated **Light/Dark Mode toggle**, allowing users to seamlessly transition between an atmospheric night-sky background and a bright, clean cloudscape theme.

---

## ✨ Key Features

- **Personal Branding:** Displays a clean layout featuring a profile avatar, username (`@shiryuu`), personality badge (INFP), and zodiac indicator.
- **Interests & Culture:** Highlights a passion for anime, K-pop, and dream travel destinations (Japan and Korea) through vibrant visual cards and flag badges.
- **Music Integration:** Features an interactive Spotify audio embed showcasing favorite tracks (like UNIS - *Whateva*).
- **Social Bio Links:** Centralized, clean button layout routing visitors directly to active professional and social networks including GitHub, LinkedIn, Facebook, and TikTok.
- **Dynamic Theming:** Smooth transitions between light and dark modes that completely transform the aesthetic from a cozy starry night to a bright, airy sky.
